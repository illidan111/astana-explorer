# Astana Explorer

Интерактивная карта Астаны: места, демонстрационные события, поиск, категории и избранное. Приложение написано на обычных HTML, CSS и JavaScript и сохраняет существующую карту Leaflet с кластеризацией маркеров.

## Запуск

Нужен Node.js 20 или новее. Сборка не требуется.

```sh
npm start
```

Откройте http://127.0.0.1:4173. Сервер доступен только на этом компьютере. Если порт занят, остановите предыдущий сервер или задайте переменную окружения `PORT`.

Для работы самого приложения установка npm-зависимостей не нужна. Любой другой статический сервер также подойдёт. Открывайте проект через HTTP/HTTPS: геолокация работает только на localhost или HTTPS и требует разрешения браузера.

## Возможности и данные

- Карта и список показывают одинаковые результаты поиска и фильтрации.
- Повторное нажатие выбранной категории снимает её, сохраняя поисковый запрос. Закрытие карточки сохраняет фильтры, прокрутку списка и положение карты.
- Поиск учитывает название и описание; карточка открывается из списка или с маркера.
- Избранное и тема сохраняются в `localStorage` этого браузера. При запрете хранилища выбор действует до обновления страницы; приложение сообщает об ограничении сохранения.
- В подборке 12 мест и 3 **демонстрационных события**. Координаты перепроверены по опубликованным картам площадок и туристических источников; `coordinateSourceUrl` в [data.js](data.js) хранит источник каждой точки. Точки обозначают объекты, а не проверенные входы. События связаны со своими площадками через `venueId`.
- Кнопка маршрута открывает Google Maps. Для приблизительных точек и событий открывается поиск площадки по названию. Геолокация запрашивается только после нажатия пользователя.
- События — примеры возможностей приложения, а не актуальная афиша. Расписание, наличие билетов и цены не подключены к внешним источникам.
- Реальное наполнение афиши требует отдельного API или редакционного источника. Не добавляйте актуальные даты, цены и часы без проверки и указания источника.
- Leaflet и его плагин кластеризации находятся локально в `vendor/`; обе темы используют тайлы OpenStreetMap без API-ключа. Тёмное оформление применяется в браузере. Каталог работает независимо от загрузки карты. При недоступности карты показывается сообщение и возможность повторить загрузку; поиск, карточки и избранное остаются доступны.

## Проверка

Только для разработки и тестов:

```sh
npm ci
npx playwright install chromium
npm test
```

В Windows конфигурация автоматически использует установленный Microsoft Edge, поэтому скачивание Chromium можно пропустить. Произвольный Chromium-совместимый браузер можно указать переменной `PLAYWRIGHT_EXECUTABLE_PATH`.

Playwright запускает локальный сервер при необходимости и проверяет интерфейс в настольном и мобильном размерах, поиск, фильтры, избранное, диалоги, карту, геолокацию, клавиатуру и доступность с axe. Отдельные сценарии покрывают короткие и горизонтальные экраны от 320×400, сохранение прокрутки и фокуса, быстрые изменения поиска, медленную загрузку карты и восстановление после сбоев. Также проверяется повреждённое/запрещённое хранилище. Реальная загрузка тайлов в основном сценарии требует доступа к сети. Снимки при ошибках и трассировки находятся в `test-results/`, итоговые снимки и сетевые диагностики — в `.qa/`; эти каталоги не коммитятся. Для визуального запуска тестов используйте `npm run test:ui`.

Проверки браузера с автоматизацией не заменяют тест на физическом телефоне, проверку VoiceOver/TalkBack и разрешения реальной геолокации. Доступность внешних карт и маршрутов зависит от сети и провайдера.
